# WQO_SHIRITORI
色んなWQOを楽しみながらしりとりができるサイトです。
β版なので予告なく変更される可能性があります。


## 文字集合
ひらがな、アルファベット、数字から選べます。ユーザー側で使う文字を指定することもできます。

## ひらがなの扱い
しりとりにおける濁点や小文字の扱いには流儀が色々あるので、文字集合でひらがなを選んだ場合はその辺を色々カスタマイズできるようにしてあります。

なお、通常のしりとりでは濁点付き文字で終わる文字列の後に濁点を取り除いた文字から始めても良いとする流儀がありますが、この流儀を採用するとこのサイトでは濁点を抜いた同一文字列として判定されます。
例えば、「こばん」と「ごはん」が同一視されます。

## 「ん」の禁止
しりとりのルールとして一応末尾が「ん」の文字はデフォルトで廃するようになってます。ですがWQOを楽しむには割と邪魔なので、私は常時OFFにしてます。

## 同一文字列禁止の拡張
本サイトの売りです。13種類くらいルールがあります。最初の4つを除きWQOなので、しりとりの有限性が保証されます。

### 1. 同一文字列禁止
普通のしりとりにもよく付いてくるルールです。同じ文字列を宣言してはいけません。

### 2. 前置部分文字列禁止
既に宣言された文字列の右に0文字以上付け足した文字列を禁止します。例えば「**ずんだ**」が既に言われていたら、「**ずんだ**もん」と言ってはいけません。「ずんもだん」とかなら「ずんだ」の右に文字を付け足しただけでは作れないのでOKです。

### 3. 後置部分文字列禁止
既に宣言された文字列の左に0文字以上付け足した文字列を禁止します。例えば「**まき**」が既に言われていたら、「つる**まき**」と言ってはいけません。「まきあーと」とかなら「まき」の左に文字を付け足しただけでは作れないのでOKです。

### 4. 部分文字列禁止
既に宣言された文字列の左右に0文字以上付け足した文字列を禁止します。例えば「**きりん**」が既に言われていたら、「じゃいあんと**きりん**ぐ」と言ってはいけません。「きりたん」とかなら「きりん」の左右に文字を付け足しただけでは作れないのでOKです。

### 5. 部分列禁止
既に宣言された文字列に(文字列の途中でも左右でもよいので)0文字以上付け足した文字列を禁止します。例えば「**きりん**」が既に言われていたら、「**きり**た**ん**」と言ってはいけません。「きんりうわのせ」とかなら「きりん」に文字を付け足しただけでは作れないのでOKです。

### 6. 冪等部分列禁止
既に宣言された文字列に0文字以上付け足したり、連続した同じ文字を1つの文字にする操作で得られる文字列を禁止します。例えば「**きつつき**」が既に言われていたら、「**きつき**」を部分列にもつ言葉も言えなくなるので、「かみ**きつき**」と言ってはいけません。「はつき」とかなら「きつつき」の連続した同じ文字を一纏めにしたり文字を付け足すだけでは作れないのでOKです。

### 7. 可換部分列禁止
既に宣言された文字列に0文字以上付け足したり、文字の順番を入れ替えたりして得られる文字列を禁止します。例えば「**りりせ**」が既に言われていたら、「**せりり**」と言ってはいけません。「かりんせんぱい」とかなら「りりせ」に文字を付け足したり文字を交換しただけでは作れないのでOKです。

### 8. 使用文字包含禁止
既に宣言されたある文字列に使用された文字を全て含む文字列を禁止します。例えば「**めいかひめ**」が既に言われていたら、「だ**め**ーじ**かいひ**」と言ってはいけません。マジで関係ない文字列を言いましょう。せいぜい文字集合の冪集合濃度と同じターンしか続けられない早期決着型のルールです。

### 9. 末尾文字一致禁止
既に宣言された文字列と末尾が一致する文字列を禁止します。せいぜい文字集合と同じターンしか続けられない早期決着型のルールです。

### 10. 右gap部分列禁止
説明がめんどいので後で書きます。

### 11. 右弱gap部分列禁止
説明がめんどいので後で書きます。

### 12. 左gap部分列禁止
gap部分列かどうかは左右反転すると変わってしまうので反転差分を用意しました。

### 13. 左弱gap部分列禁止
こちらも反転差分となります。

## 相互モード
例えば部分列ルールの場合、「きりん」の後に「きりたん」と言ってはいけませんが、逆に「きりたん」の後に「きりん」を言うことは許されています。相互モードではこれらを相互に禁止します。

順序集合の言葉で言うと、通常モードは悪列(反上昇列)となるように文字列を宣言し続けるモードで、相互モードは反鎖となるように文字列を宣言し続けるモードです。WQOであればどちらにせよ有限です。

## 文字列長の下限と上限
iターン目の文字列の長さに下限や上限を設けることができます。ちなみに上限を設けるとKőnigの補題によりターン数にも上限ができます。

下限や上限は、ターン数、四則演算、最大最小、絶対値、床関数、指数対数、冪根、テトレーションの逆関数などを組み合わせて表すことができます。うまくやればWQOの相転移で遊べるかもしれません。

## 接続文字数
しりとりの亜種として、末尾2文字を次の文字列の先頭2文字にするような言葉遊びもあるので、接続文字数を一般化しました。こちらも定数だけではなくターン数に応じて変動させることができます。

接続文字数が0なら通常の悪列、1なら悪列しりとり、2なら悪列2文字とりとなります。

### LONG FINITE SEQUENCES
これは偶然なのですが、iターン目をちょうどi+1文字となるように設定し、iターン目のi-1ターン目から引き継ぐ接続文字数をi-1とする設定にすると、FriedmanによるLONG FINITE SEQUENCESに出てくる関数nの条件を満たす列を2文字ずつ伸ばしていくゲームと同型になります。

## プレイ人数
対戦は2～10人の範囲で選べます。名前の入力もできます。

脱落式で、ルール違反したプレイヤーはその後ターンを飛ばされます。ルール違反していないプレイヤーが1人しかいなくなった時点でゲーム終了です。

1人プレイの場合は、自分がルール違反するまでゲームを続行します。

0人を選ぶと雑に思いついた悪列生成アルゴリズムによって長くプレイ様子が見られます。こっちは色々雑なので、最大列になるとは限らないことに注意してください。ポンコツお手本アンドロイドを愛しましょう。
